# 👻 GhostShell: The Haunted CLI Companion

**GhostShell** is a local-first, open-source AI project built for the [DEV "Ghost in the Machine" Challenge](https://dev.to/challenges). It "possesses" your terminal using **Gemma** to provide eerie, context-aware commentary on the commands you run.

## 🌟 Why Open Innovation Matters
- **Privacy**: Your command history and file names never leave your machine.
- **Offline**: Works in the dark, with the Wi-Fi off (perfect for spooky séances).
- **Control**: You can fine-tune the "ghost's" personality by modifying the local Gemma prompt.
- **Cost**: Zero inference costs.

## 🛠️ Tech Stack
- **Language**: Python
- **AI Model**: [Gemma](https://ai.google.dev/gemma) (via Ollama)
- **Environment**: Local Terminal

## 🚀 Features
- `ghostshell <command>`: Executes a command and returns a ghostly whisper from Gemma.
- `ghostshell --possess`: Enters an interactive mode where every command is observed by the "Ghost in the Machine".
- `ghostshell --ofrenda`: Generates a "Digital Ofrenda" — a poetic remembrance of your technical activity and "dead" projects.

## 👻 How to Run
1. Install [Ollama](https://ollama.ai/).
2. Pull Gemma: `ollama pull gemma2:2b`.
3. Run GhostShell: `python ghostshell.py ls`.
